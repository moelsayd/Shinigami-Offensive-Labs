[Hint 1] To activate /debug, send `POST /init` with header `X-Init: true`. The response will give you a session cookie.
[Hint 2] The config file at /config gives the API key and the internal service URL.
[Hint 3] The cache service at port 9402 uses the Host header to generate cache keys. You can poison it by sending `POST /cache/poison` with `Host: evil`.
[Hint 4] After poisoning, request `GET /cache/data` with `Host: evil` and the API key to get the real flag.
